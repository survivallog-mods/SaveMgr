# 注入链路与存档机制实机实录（2026-10-31，三轮自驱会话）

> 方法：SaveInjectProbe 探针（suite 内，永不发版）+ SaveMgr cmd.txt 文件触发通道 + CDP 驱动
> 游戏内 WebUI（ViewportProbe DevTools 9222）+ WM_CLOSE 优雅退程。全程自动化，无人工操作。
> 本实录**推翻并修正了静态分析的四条结论**，是 DESIG N 当前形态的依据。

## 轮次一：snap 字节注入 → 失败（关键否定）

复制最新 `.snapN.bytes` → 新档名 → `AddHistoryEntry`：
- `PeekGameSave` 返回 null → `metaV2=False` → 列表过滤不显示。
- **结论①**：`.snapN` 是 `RebirthDaySnapshot` 包装（dump.cs:87451：`{Version, Day, SaveFileName, Child:SaveChildData}`——**元数据**，非完整档）。静态分析"与主档同构"错误。

## 轮次二：主档字节注入 → 列表仍不显示 → 两个真凶

复制主档（真 `GameSaveData` 字节）→ 新名 → `AddHistoryEntry(newName, "探针注入")`：
- `metaV2=True, day=117, player=3` ✓ 但列表不渲染。
- **真凶 A（Name 约束）**：`AddHistoryEntry` 的 name 参数被 `ParseSaveTimeShort` 当**时间戳解析**渲染行内时间列；原档 `child.Name="2026_09_19_09_30_35"`。非时间串 → 行被丢弃。传 `Save_yyyy_MM_dd_HH_mm_ss` 去掉前后缀的时间戳串后正常显示（列表顶部「首轮·自定义·10/31 21:30」）。
- **真凶 B（身份字段）**：进入注入档游玩一次结算后，**原档主文件被改写、原档名下多出 snap4**——注入档字节内部的 `GameSaveData.FileName`(0x18) 仍指原档，游戏一切持久化按**数据内身份**路由！
- 副产物（机制修正）：该轮结算时 hook 触发（`CaptureDaySnapshot(day=118)`）但注入档自身主档/snap **零写入**（写全去了原档名下）——结合原档（无尽档）今日 snap0-3 全在结算时刻：**"每结算写盘"是无尽/轮回系统行为；普通档结算与退出（WM_CLOSE 验证）均不落盘**。静态分析"CaptureDaySnapshotCore→SaveGameFileCore=结算写主档"只在无尽快照上下文成立。

## 轮次三：身份重写注入 → 全链路通过（最终形态）

```
① File.Copy(备份 → Saves/Save_<生成器新名>.bytes)
② 身份重写：gs = gsm.PeekGameSave(新名)；gs.FileName = 新名；gs.Name = 时间戳串；
   SerializeObject(gs) → TemporaryFile.WritFile 写回   ← 全走游戏自己的 API，零私有格式
③ gsm.AddHistoryEntry(新名, 时间戳串)
```

实测（21:46-21:50）：
- 注入条目上列表（列表顶部）；点进**可玩**（进入战斗 UI）。
- 满速跑到日结算：`hook: CaptureDaySnapshot(day=118)` → `auto: 请求游戏持久化（SaveGame）` → **2 秒后** `auto: D118_20261031_214947` 落备份（SaveGame 强制持久化 → 主档 mtime 变化 → 字节级抄走）。
- **独立性**：注入档写盘只落自己（自己主档 + 自己 snap4 + 备份目录按自己档名），**原档 mtime 全程不动**，前身档不动。
- 守卫负测试：局内 cmd restore 被拒（not-at-main-menu）。

## 其它实机发现（实现细节库）

1. `GetLastPlayFileName()` 带返回 `.bytes` 后缀；全链（HistoryChild.FileName / AddHistoryEntry / IsSaveFilePresent / GetFilePath）同口径带后缀；`GenerateNewSaveFileName()` 输出也带。
2. 主菜单冷启动 ~10s 内 `GetLastPlayFileName` NRE（游戏源:421）；先调幂等 `EnsureHistoryV2Migrated()`（原生 RebuildSaveList 同款防御）即恢复。**局内**该调用持续 NRE（战时 historyData 卸载）→ 档名需菜单期缓存。
3. 键盘注入（SendKeys/SendInput 扫描码）对 Unity Input 全部无效（F11/ESC 均不达）——自动化验收走 cmd.txt 文件触发通道（F9/F10 热键留给玩家）。
4. 优雅退程：`Process.CloseMainWindow()`（WM_CLOSE）→ 游戏走 OnApplicationQuit 正常存档退出。
5. 游戏 runtime 已自更 **1.1.20151**（gamekb 为 19611）：`CaptureDaySnapshot` 锚点实测仍命中（patch 挂载成功+结算触发），AddHistoryEntry/PeekGameSave/SerializeObject/WritFile 行为如常。
