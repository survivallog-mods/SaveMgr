# 更新说明（SurvivalLog.SaveMgr）

## v1.0.1（2026-11-01）

- **修复：存档点类型标签**——每日结算自动存档/「立即存档」新增的存档，读档列表现与原档一致显示
  「无尽（纯净无尽）/ 剧情无尽」标签。根因：注册原语 AddHistoryEntry 只回填进度 meta，无尽块
  （IsPureEndless/IsStoryEndless 等）游戏原生仅在建条目时直写、常规存盘也不回填（GameAssembly
  反汇编实证），此前新档条目永不显示类型标签。现注册时从原档条目复制回填（游戏公共属性，
  与原生转档 ForkCore 同款写法）并即时落盘 HistorySave。纯显示修复：无尽玩法状态本就存于档字节，
  修复前后读档游玩均不受影响
- pending.json 队列格式扩展 {f,s}（s=原档名，供类型回填），兼容旧版纯档名数组；旧队列注册时
  回落"当前档名"取类型

## v1.0.0（2026-11-01）

首个正式版。存档管理：**存档点与官方存档同列同管，零隐藏副本**。

- **立即存档**（局内 ESC 暂停菜单按钮）：原地存当前进度为新档——不退出、不覆盖原档；
  结算同构持久化（暂停态秒落盘）；进档 30 秒保护期（按钮显示"准备中"，防进档流程竞态崩溃）；
  存档过程"正在存档…"防重复点击；新档身份重写（原档绝不被写坏）
- **自动存档点**（每日结算触发）：间隔天数可设（默认 5；0=关、1=每天）；等游戏结算写盘后取档
  （无尽类结算落盘；普通档结算不落盘则跳过该天）；下个主菜单自动补注册
- **读取/回档** = 主菜单官方「读取存档」列表（存档点与官方档同列表，× 即删）
- **崩溃/强退不丢**：进度即时写主档；新档字节即时落盘；未注册名单 pending.json 落盘 + 启动补扫，
  下次到主菜单自动补注册（注意：卸载 mod 前请先回一次主菜单，让存档点永久入列表）
- **设置仅 2 项**（游戏内 MOD 管理面板）：启用自动存档 / 自动存档间隔天数
- 热键与调试通道：cmd.txt 文件触发（manual/tomenu）保留供自动化
