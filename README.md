# 存档管理 SaveMgr（Survival Log MOD）

> 作者 Night · 抖音 166660371 · 免费分享 · 仅供个人使用，禁止二次分发
> **状态：设计定稿待作者批，功能开发中，未发版。**

## 一、这是干什么的

游戏只有 4~6 天的滚动快照，超窗即覆盖；想回档没有后悔药。本 mod 提供：

- **每日结算自动存档**：间隔天数可设（默认 3 天，1=每天，0=关闭）
- **手动存档**：局内 HUD「立即存档」按钮（F9 同效）
- **备份管理**：列表 / 删除 / 导出 zip 长期保存
- **一键回档**：把备份注入游戏原生读档列表成新档入口——**原档不动，随时可再回**

## 二、使用与已知行为

- **局内 HUD 按钮**（进游戏后右侧）：「**立即存档**」随手备份；「**读取存档**」=存当前进度并弹出
  **官方存档列表**——备份/回档都在官方列表里直接挑，主菜单不加任何按钮
- **游戏内设置**：主菜单或局内 ESC 菜单 →「MOD 管理」→「存档管理」，仅 3 项：启用自动存档 /
  自动存档间隔天数（**默认 5**）/ 每档保留上限
- 自动备份=每日结算时强制让游戏持久化一次并抄走主档（1=每天；0=关闭）
- 备份/导出=普通文件夹（`BepInEx/plugins-data/SaveMgr/backups/<档名>/`），资源管理器直接管理；MVP 阶段不做面板
- 回档档的时间列显示注入时刻；原生"时光回溯"对回档档为空窗（重新积累）；原档永不被动

## 三、安全与还原

- 备份全部落在 `BepInEx/plugins-data/SaveMgr/`，字节级复制，不解析存档格式
- 对游戏存档目录的写入只有一种：恢复时复制备份成**新档名**（走游戏自己的反序列化/序列化与 `AddHistoryEntry` API 注册，含身份重写），从不改写现有存档
- 持久化请求走游戏自己的 `SaveGame()` 公开 API（与游戏退出存档同款）
- 删除 dll 即还原原版；备份文件保留在 plugins-data 由玩家自行处置

## 四、安装与卸载

需先装好基座（见 SurvivalLog.Base 包）。把 `BepInEx\plugins\SurvivalLog.SaveMgr.dll` 放进游戏 `BepInEx\plugins\`，重启游戏即生效。
