# 锚点实证——写盘同步性与模式 gating（2026-10-31，Task 1）

> 工具：suite `disasm_tool`（Iced），gamekb `2026-10-23_26157732`，产物存 `.superpowers/sdd/`（临时）。
> 结论：**postfix `CaptureDaySnapshot` 锚点成立**；写盘异步未等待 → 复制必须等 mtime 稳定+md5 双读（预案转正，非兜底）。

## ① 写盘同步性：**异步，postfix 返回时文件未落盘**

- `CaptureDaySnapshotCore`(0x28D1E30)：`GetSnapshotSlotCount → GetSnapshotPath → SerializeObject → TemporaryFile.WritFileAsync`（0x297EC70，**Async**，写的是天数记录等侧车）→ 旧快照 File.Delete 轮转 → **直接 `call SaveGameFileCore`**(0x28D2367) 写 .snapN 本体。
- `SaveGameFileCore`(0x28E2410)：`ValidateIntegrityBeforeSave → SerializeObject → **TemporaryFile.WritFileAsync（未等待——SaveGameFileCore 是常规 void 方法，无法 await）** → SyncHistoryChildMeta → PersistHistoryData → RebuildIntegrityBaseline`。
- 外层 `CaptureRebirthDaySnapshot`(0x26CB730) 套 **`BeginBatchSave → SaveGame → CaptureDaySnapshot → EndBatchSave`**（batchSaveDepth/batchSavePending 机制，写盘再延迟一层到 EndBatchSave flush）。

**定论**：postfix `CaptureDaySnapshot` 只作**时机信号**；字节复制必须等目标 snap 的 mtime 稳定后进行，md5 双读重试（≤3×500ms）从"兜底"**转正为必要路径**。BackupStore 设计已覆盖。

## ② 模式 gating：**自然日翻转无门控，postfix 锚点全模式成立**

- `CountUpTimer.CostTime`（0x26CB810）内两个调用点：
  - **调用点 A**（0x26CBBB8→C7）：被单例 `[5B9E9E0]+0x1D` 的 bool 门控——**= `C2S_Permissions.IsSkipDailySettlement`**（手机权限"跳过每日结算"；开则跳过该路径的快照）。属"玩家显式买跳过结算"的 QoL 权限，非模式差异。
  - **调用点 B**（0x26CBC01→1A）：时间累加器跨日 → `day++ → TriggerDaySettlement() → CaptureRebirthDaySnapshot()`——**无条件，无任何模式/槽位门控**。这是常规日翻转主路径。
- **无尽模式**：同一 `CostTime` 紧邻处直接驱动 `EndlessManager.OnHourChanged`（0x26CBB9E）——无尽与常规共用 CountUpTimer 日翻，锚点覆盖无尽。休闲另有 `TryCaptureCasualEntrySnapshot` 路径但日翻快照同走 B 路径。
- 外层 `CaptureDaySnapshot`(0x28D2640) 是薄 try/catch 包装，无门控；postfix 每次调用必触发。

**已知边界（实现注意）**：
1. `GetSnapshotSlotCount()`（0x28DC460，读全局设置 RebirthSnapshotSlots）在 Core 内部——若玩家把快照槽位设为 0，Core 早退、**postfix 仍触发但无新 snap 落盘**。对策：OnSettlement 只在 `NewestSnapPath` 的 mtime 距今 ≤120s 时才采用，否则跳过本次自动备份并 trace（防"旧 snap 标新天"）。
2. 玩家开"跳过每日结算"权限时调用点 A 被跳过；调用点 B（自然跨日）不受影响——但保险起见 DayWatcher 兜底保留。

## 锚点定案（供 Task 7 执行）

- **主锚点**：Harmony postfix `GameSaveManager.CaptureDaySnapshot(int day)`（公开常规方法，无 async 状态机问题）。
- **兜底**：DayWatcher（Ticker 轮询天数增量），默认开。
- **字节源选取**：`NewestSnapPath` 且 mtime ≤120s；否则跳过+trace。复制走 md5 双读稳定 + IO 重试。
